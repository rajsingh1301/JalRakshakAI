# JalRakshak AI

Uncovering Invisible Water Threats Through AI.

An evidence-led groundwater monitoring dashboard for the Avaloka Hackathon 2026. Implementation is in progress. Government source measurements and reproducible calculations will be kept separate from verified Avaloka findings.

```sh
npm install
npm run dev
```

Secrets belong in the ignored local `.env` file. Never put an Avaloka token in frontend code.
